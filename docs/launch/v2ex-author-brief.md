**这不是可直接发布的帖子。** V2EX 的 [About 页面](https://www.v2ex.com/about) 明确要求：“请不要把 AI 生成的内容发送到这里”。请根据亲身开发和使用经历自己写标题、正文及回复，不要直接粘贴本仓库的 AI 辅助介绍稿。

## 作者可以组织的内容

| 顺序 | 要说明的事实 | 需要作者自行补充的经历 |
| --- | --- | --- |
| 1 | 项目是中英文 DOCX 写作与审阅工作台，提供 Codex/Claude Code skill | 为什么开始做；曾在哪种文档修改任务中遇到问题 |
| 2 | 选区和修改指令绑定，建议可对照并逐项应用为 Word 修订 | 自己实际用过的一处改写及它带来的帮助 |
| 3 | 从提纲逐段写入；已有内容可继续阅读标注 | 最常用的是导入润色还是从零写作 |
| 4 | Python 3.11+；skills.sh 安装另需 Node.js 22.20+；运行 ZIP 自带前端，运行时不需要 Node.js | 自己验证过的系统和安装方式，引用当前 README 和安装验收报告 |
| 5 | 浏览器版式预览是近似值；公式、脚注等受保护；当前为候选版 | 尚未解决或希望用户帮助发现的问题 |
| 6 | MIT、公开源码、运行包和验收概览 | 希望用户优先反馈的一个具体问题 |

标题的必要信息：产品名、Word/DOCX、精确改写或修订审阅、开源。由作者自行选择一个主要能力写成自然标题，无需把所有功能放进去。
